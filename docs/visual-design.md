# Visual design update

User-approved direction: navy sidebar, blue-gray workspace, teal accents and professional cards. Implemented with Streamlit's native theme, containers, badges, metrics and layout primitives; no remote font or CSS dependency.

Palette: navy #102238 research panel; blue-gray #EAF0F6 workspace; teal #087F83 primary actions; dark navy #142B43 headings and comparison-table header. Sidebar text and widget colors are configured independently for contrast. Compact type scale and rounded borders distinguish sections.

The landing view introduces the demo market and three workflow cards. Results use four bordered metric cards, an enclosed comparison snapshot, opportunity cards with experiment/measurement columns, expandable caveats, and a separate human-review card. Existing graph logic, credentials, evidence behavior and approval requirements remain intact. No API credentials are required for visual review in recorded mode.
